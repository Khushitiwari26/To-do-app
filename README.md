#To-Do App
A simple and easy-to-use To-Do list web app built using HTML, CSS, and JavaScript. You can add, edit, and delete tasks. All your tasks are saved in the browser using localStorage.

Features
1) Add new tasks
2) Edit existing tasks (edit box appears in the center)
3) Delete tasks with confirmation
4) Tasks saved even after refreshing (uses localStorage)
5) Clean and responsive design

Files Included
1) index.html – Main structure of the app
2) style.css – Styling of the app
3) script.js – Functionality of the app
4) README.md – Project details

How to Use
1) Download or clone the project folder.
2) Open the index.html file in your web browser.
3) Start adding tasks!

Future Ideas
1) Add due dates
2) Add task categories
3) Mark tasks as completed
4) Search or filter tasks

Tech Used
1) HTML
2) CSS
3) JavaScript
4) LocalStorage API
